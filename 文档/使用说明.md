# 数字孪生平台 · 使用说明

> 文档版本：2026-07-31  
> 适用产品：Digital Twin Platform（3D Editor · 数字孪生平台）  
> 技术栈：Three.js + React + TypeScript

本文面向**编辑器使用者**，按「点哪个按钮、按什么顺序」说明操作流程。

**推荐阅读图文版（含界面截图与切图标注）：** 用浏览器打开同目录 [`使用说明.html`](./使用说明.html)。截图资源在 [`使用说明-assets/`](./使用说明-assets/)。

---

## 一、平台定位与能力

### 1.1 解决什么问题

数字孪生、智慧园区、设备展厅等场景里，常见痛点是：

- **交付链路长**：建模、调光、做界面、写交互、再部署，往往要跨多个工具与多人协作，周期长、沟通成本高  
- **演示难落地**：有 3D 模型却缺少可点击的业务界面，或有大屏 UI 却无法真正驱动三维相机与设备状态  
- **成果难复用**：调好的场景只能在编辑器里看，不便导出为可静态托管的演示包继续演示或二次嵌入  

本平台把 **3D 场景搭建、材质灯光、相机漫游、2D UI 编排、UI↔场景联动、一键导出** 收拢到同一套轻量编辑器中，缩短「从模型到可交互演示」的路径。

### 1.2 满足什么需求

| 角色 / 场景 | 典型需求 | 平台如何支撑 |
|-------------|----------|--------------|
| 方案演示 / 售前 | 快速搭一个可点击的三维展厅 | 导入 GLB、调环境与灯光，导出可部署包 |
| 数字孪生可视化 | 设备标注、漫游参观、点按钮看设备 | 场景标签、站点/曲线漫游、UI 交互绑定 |
| 内容制作 | 少写代码也能改材质、HDR、后期 | 面板化编辑 + Poly Haven 模型/贴图/HDR |
| 交付与托管 | 给客户一个解压即开的网页包 | 场景运行包 / 完整部署包（含 UI 与交互） |
| 持续迭代 | 改完还能接着编 | 保存 / 打开完整项目（场景 + UI） |

### 1.3 核心能力概览

- **三维场景**：本地 / Poly Haven 模型导入，几何体、灯光、粒子、标签组件库，场景树与变换编辑  
- **视觉表现**：多材质与 UV、PBR 贴图、HDR 环境、雾效、后期处理  
- **空间叙事**：站点漫游、一镜到底路线，可录制漫游视频  
- **业务界面**：UI 编排多页面画布，按钮等组件可绑定相机、显隐、变换等场景动作  
- **闭环验证**：联动预览中直接点 UI 驱动 3D  
- **产出物**：保存可回编项目；导出 GLB / 截图 / 配置 JSON / 场景运行包 / 含 UI 的部署包  

### 1.4 推荐工作流

1. **场景编辑**：导入模型 / 摆放几何体 → 调材质与灯光 → 配环境与后期  
2. **漫游 / 标签**（可选）：配置相机漫游路线、添加场景标签或粒子  
3. **UI 编排**（可选）：设计 2D 界面，并绑定场景交互  
4. **联动预览**：验证 UI 点击能否驱动 3D  
5. **保存 / 导出**：保存可回编项目，或导出可部署包  

环境安装与启动命令见仓库根目录 `README.md`。

## 二、界面总览（先认按钮）

> 带编号的全界面截图见 `使用说明.html` 第 2 节。

### 2.1 布局与对应操作

| 区域 | 你看到什么 | 怎么用 |
|------|------------|--------|
| 顶部正中 | **场景编辑 / UI 编排 / 联动预览** | 点击切换整套工作台 |
| 顶部右侧 | **打开项目、保存项目、导入模型、模型库、导出场景** | 依次完成存取与进出资源 |
| 左侧上半 · 场景树 | 对象列表 +「搜索对象…」 | 点击名称选中；可重命名 |
| 左侧下半 · 组件库 | **灯光 / 几何体 / 粒子 / 标签** 页签 | 先点页签，再点具体按钮添加到场景 |
| 中央视口 | 网格 + 坐标轴 | 左键拖旋转、滚轮缩放；点击物体选中 |
| 视口底部工具 | 选择 / 移动 / 旋转 / 缩放 | 或按 `Q` `W` `E` `R` |
| 右侧属性 | 未选中：场景/环境/渲染/漫游/后期；选中：详情/材质 | 先点顶部小页签，再改控件 |
| 底部状态栏 | 当前工具、FPS、对象数等 | 仅查看 |

切换到 **UI 编排** 后：左上组件库、左下图层、中间画布、右侧「画布 / 组件 / 交互」。

### 2.2 三种编辑模式（点击哪里）

1. 点顶部 **场景编辑**（默认高亮）：搭 3D、调灯光材质、做漫游。  
2. 点 **UI 编排**：做 2D 页面，并在右侧「交互」里绑定场景动作。  
3. 点 **联动预览**：叠层联调；通过后点右上角 **导出部署包**。  
4. 预览中按 `Esc` 退回场景编辑。

## 三、场景编辑

### 3.1 导入模型

**本地文件**

1. 场景编辑模式下，点击工具栏 **导入模型**  
2. 选择 `.glb` / `.gltf`（支持 Draco 压缩，可多选）  
3. 模型进入场景后，在场景树中选中并调整位置

**Poly Haven 模型库**

1. 点击 **模型库**  
2. 浏览 / 搜索在线模型，选择分辨率后导入  
3. 需联网；导入时间取决于模型大小与网速

### 3.2 组件库

左侧 **组件库** 分四个页签：

| 页签 | 可添加内容 |
|------|------------|
| 几何体 | 立方体、球体、圆柱体、平面 |
| 灯光 | 环境光、平行光、点光源、聚光灯、半球光 |
| 粒子 | 预设粒子发射器（如烟雾、火花等） |
| 标签 | 场景 HTML 标签（CSS2D / CSS3D / CSS3DSprite） |

点击条目即可在场景中生成对应对象，并自动选中以便编辑。

### 3.3 选择与变换

- 视口中点击对象，或在场景树中点击名称进行选中  
- 左下角工具或快捷键：

| 工具 | 快捷键 | 说明 |
|------|--------|------|
| 选择 | `Q` | 仅选中，不显示变换手柄 |
| 移动 | `W` | 平移 Gizmo |
| 旋转 | `E` | 旋转 Gizmo |
| 缩放 | `R` | 缩放 Gizmo |

右侧 **详情** 面板也可精确修改位置、旋转、缩放数值，并切换对象可见性。

### 3.4 场景树

- 查看场景中的模型、几何体、灯光、粒子、标签等  
- 支持选中、重命名（回车确认，`Esc` 取消）  
- 删除选中对象：`Delete` / `Backspace`（焦点不在输入框时）

### 3.5 撤销 / 重做

| 操作 | 快捷键 |
|------|--------|
| 撤销 | `Ctrl+Z`（Mac：`Cmd+Z`） |
| 重做 | `Ctrl+Y`（Mac：`Cmd+Y`） |

> **注意**：当前历史主要覆盖**变换**（移动 / 旋转 / 缩放）。材质修改、增删对象、灯光变更等尚未完整纳入撤销栈。重要节点请及时 **保存项目**。

### 3.6 视口辅助

| 快捷键 | 功能 |
|--------|------|
| `G` | 显示 / 隐藏网格 |
| `H` | 显示 / 隐藏坐标轴 |

视口中可用轨道控件旋转、平移、缩放观察视角（鼠标操作与常见 3D 编辑器一致）。

## 四、材质与贴图

1. 选中带网格的对象  
2. 右侧切换到 **材质** 页签  
3. 可切换材质类型（约 17 种，常用：`MeshStandardMaterial`、`MeshPhysicalMaterial` 等）  
4. 调节颜色、金属度、粗糙度、透明度等 PBR 参数  
5. 上传本地贴图，或使用 **从 Poly Haven 选择贴图** 应用在线 PBR 贴图集  
6. 在 **UV 设置** 中调节：重复、偏移、旋转、包裹模式，以及贴图 UV 动画

未选中对象时，右侧展示的是全局设置，不会出现材质页签。

---

## 五、灯光

1. 组件库 → **灯光** → 选择类型添加  
2. 在场景树或视口中选中灯光  
3. 右侧编辑颜色、强度、位置、目标点、阴影、衰减距离、聚光角度等  
4. 场景中可显示灯光 Helper，便于对齐照射方向

默认场景通常已带基础照明；可按项目需要增删与微调。

## 六、全局设置（未选中对象时）

右侧面板顶部页签：

### 6.1 场景

- 背景纯色  
- 与场景外观相关的基础参数  

### 6.2 环境

- **大气雾效**：颜色、近远距等  
- **HDR**：本地上传或 Poly Haven HDRI  
  - 可作为天空背景、环境反射，或两者同时使用  
  - 环境反射强度、HDR 水平旋转（对齐太阳方向）  

### 6.3 渲染

- 渲染器相关选项（如透明背景 / Alpha 等，便于截图或叠层导出）  

### 6.4 漫游

见下一章「相机漫游」。

### 6.5 后期

在编辑器内开启 Bloom、SSAO、FXAA、Sobel 等后期效果，并调节强度参数。导出部署包时，部分效果会按导出管线一并写入运行时配置。

## 七、相机漫游

路径：右侧全局设置 → **漫游**。

### 7.1 漫游方式

| 方式 | 说明 |
|------|------|
| **站点漫游** | 逐站停留观看设备；可为站点绑定场景中的设备对象 |
| **一镜到底** | 沿样条曲线连续参观；至少需要 2 个漫游点 |

### 7.2 常用操作

1. 新建或选择漫游路线  
2. 调整好当前相机视角，点击 **添加漫游点（当前视角）**  
3. 站点模式下：先选中设备再添加，可绑定设备名  
4. 在列表中拖动排序、跳转视角、更新某点为当前视角  
5. 可开启 **循环播放**，并在面板内预览播放  
6. 可下载漫游 JSON，供外部或导出包使用  

导出场景 / 部署包时可一并带上漫游数据；**导出场景** 面板还支持按路线录制 WebM / MP4 / 序列帧。

## 八、场景标签与粒子

### 8.1 标签

1. 组件库 → **标签** → 添加  
2. 右侧标签编辑中可设置：  
   - 渲染模式：`CSS2D`（始终朝向屏幕）、`CSS3D`（可随物体旋转）、`CSS3DSprite`  
   - 内容：纯文本，或嵌入 **UI 编排** 中的某一页  
   - 字号、颜色、背景、边框、缩放等  

适合设备名、测点、铭牌、信息面板等数字孪生标注。

### 8.2 粒子

从组件库选择预设粒子放入场景，在属性面板中调节发射器相关参数。可用于烟雾、火花等氛围效果。

## 九、UI 编排

切换到顶部 **UI 编排**。

### 9.1 布局说明

| 区域 | 作用 |
|------|------|
| 左上 · 组件面板 | 拖入或添加按钮、文本、图片等 UI 组件 |
| 左下 · 图层树 | 管理页面内图层层级与选中 |
| 中央 · 画布 | 可视化排布界面；支持多页面 |
| 右侧 · 属性 | 尺寸、样式，以及 **场景交互** |

画布内快捷键（焦点在画布相关区域时）：

- `Ctrl+C` / `Ctrl+V`：复制 / 粘贴组件  
- `Delete` / `Backspace`：删除选中组件  

### 9.2 场景交互

选中 UI 组件后，在右侧 **场景交互** 中添加动作，例如：

- 点击后切换物体显隐  
- 相机飞向某目标 / 设置视角  
- 变换物体位置、旋转、缩放  
- 修改颜色等  

配置完成后，切到 **联动预览** 验证点击是否生效。

### 9.3 导出界面

在 UI 编排模式下，工具栏 **导出界面** 可单独导出 UI 相关产物（不含完整 3D 部署包）。完整交付请使用联动预览下的 **导出部署包**，或场景模式下的「场景运行包」。

## 十、联动预览

1. 切换到 **联动预览**  
2. 视口显示 3D 场景，并叠加上当前 UI  
3. 点击已绑定交互的按钮，观察相机 / 物体响应  
4. 确认无误后，可点击 **导出部署包**  

部署包为可静态托管的 ZIP（含 HTML/JS、场景资源、UI 叠层与交互等）。解压后用本地静态服务器预览，例如：

```bash
npx serve .
```

## 十一、项目保存与打开

工具栏（场景编辑 / UI 编排模式下）：

| 按钮 | 说明 |
|------|------|
| **保存项目** | 导出完整可回编项目（场景 + UI 画布 + 图片等），一般为 ZIP |
| **打开项目** | 导入 `.zip` 项目包，或可识别的 `.json` 配置 |

打开时若当前已有内容，会提示确认：**将覆盖当前场景与全部 UI 画布**。

兼容说明：

- 支持统一项目 ZIP（场景 + UI）  
- 旧版仅 UI 的 JSON 可打开，建议打开后重新「保存项目」以合并场景  

> 刷新或关闭页面前请手动保存。目前无自动草稿与未保存离开强提示。

---

## 十二、导出场景（场景编辑模式）

工具栏 **导出场景** 打开导出面板，主要能力：

| 类型 | 说明 |
|------|------|
| **场景运行包 ZIP** | 仅 3D 的可运行 HTML/JS 包（**不含** UI 叠层）。完整 3D+UI 请用联动预览的「导出部署包」 |
| **截图 PNG** | 当前视角截图，可设分辨率与透明背景 |
| **GLB 模型** | 导出场景模型 |
| **漫游录制** | 按已配置路线离屏录制（WebM / MP4 / 序列帧；不含网格与坐标轴） |
| **场景配置 JSON** | 相机、灯光、雾效等参数 |

典型运行包目录结构示意：

```text
digital-twin-project-*/
├── index.html
├── css/style.css
├── js/main.js
├── config/scene.json
├── assets/
│   ├── models/scene.glb
│   ├── textures/
│   └── hdr/
└── README.md
```
