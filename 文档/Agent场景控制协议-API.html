平台暴露的可调用方法

编辑器与导出部署包在场景就绪后，都会挂载 window.sceneApi。 UI 按钮、控制台、以及未来 Agent 协议接入层，都应通过这套 API 驱动场景。

入口：window.sceneApi 实现：src/runtime/sceneApi.ts 协议：SCP/1.3

1. 怎么调用

场景 / 导出包加载完成后，在浏览器控制台或业务脚本中直接调用：

// 确认已就绪
console.log(window.sceneApi);

// 示例：隐藏某个模型
window.sceneApi.setVisible('pump_01', 'hide');

// 示例：播放漫游
window.sceneApi.playTour();

// 示例：用动作对象调度（与 UI 交互绑定同一套）
window.sceneApi.dispatch({
  id: 'act_1',
  trigger: 'click',
  type: 'camera.set',
  params: {
    position: { x: 16, y: 8, z: 16 },
    target: { x: 0, y: 2, z: 0 },
    duration: 2
  }
});
编辑器内

联动预览 / 场景标签交互会调用 ensureEditorSceneApi()，把 API 挂到 window.sceneApi。

导出部署包

js/main.js 场景就绪后挂载同名 API；UI 由 ui-bridge.js 自动绑定到 dispatch。

注意：《Agent 场景控制协议》里的 WebSocket 消息接收入口尚未建设。 后台目前不能直接推 agent.expression 生效；要先调 window.sceneApi，或等协议桥接层落地。

2. 已暴露方法总览

方法 作用 返回值 对应 SCP action（规划）
setVisible 模型显示 / 隐藏 / 切换 boolean setVisible
select 选中模型并高亮 boolean （编辑器能力，协议无单独 action）
focus 相机飞向模型并注视 boolean focusObject
setCamera 设置相机位置与注视点 boolean setCamera
setMaterial 改颜色 / 金属度 / 透明度等 boolean setMaterial
setTransform 移动 / 旋转 / 缩放（可过渡） boolean setTransform
setUIVisible UI 元素显隐 boolean （UI 层，非 SCP mesh 指令）
playTour 播放相机漫游 boolean playCameraTour
pauseTour 暂停漫游 boolean —
stopTour 停止漫游 boolean stopCameraTour
dispatch 执行一条 UIAction boolean 统一调度入口
onPointPatch 仅导出包：转发测点补丁事件 — （扩展钩子）
几乎所有方法成功返回 true，找不到目标或失败返回 false（并可能在控制台 warn）。

3. 方法详解与调用示例

setVisible 可调用 模型
setVisible(objectId: string, mode?: 'show' | 'hide' | 'toggle' | boolean): boolean

控制场景对象显隐。也可用布尔值：true=显示，false=隐藏。

window.sceneApi.setVisible('pump_01', 'hide');
window.sceneApi.setVisible('pump_01', 'toggle');
window.sceneApi.setVisible('pump_01', true);  // 显示
select 可调用 模型
select(objectId: string): boolean

选中模型。编辑器内会附加变换手柄；导出包内以材质自发光做简易高亮。

window.sceneApi.select('pump_01');
focus 可调用 相机
focus(objectId: string, options?: { distance?: number; duration?: number; // 秒，默认 2 position?: {x,y,z}; // 可选：直接指定相机终点 target?: {x,y,z}; // 可选：注视点 }): boolean

根据模型包围盒计算观察距离并平滑飞入。也可手动传 position / target。

window.sceneApi.focus('pump_01', { distance: 3, duration: 1.5 });
setCamera 可调用 相机
setCamera( position?: {x,y,z}, target?: {x,y,z}, duration?: number // 秒，默认 2；0=立即 ): boolean
window.sceneApi.setCamera(
  { x: 16.3, y: 7.4, z: 15.8 },
  { x: 0, y: 3.3, z: 0 },
  2
);
setMaterial 可调用 材质
setMaterial(objectId: string, params: { nodeName?: string; // 子节点名，不传则整棵树 color?: string; metalness?: number; roughness?: number; opacity?: number; emissive?: string; emissiveIntensity?: number; }): boolean
// 告警红
window.sceneApi.setMaterial('pump_01', {
  color: '#ff3333',
  emissive: '#ff0000',
  emissiveIntensity: 0.4
});
setTransform 可调用 变换
setTransform(objectId: string, params: { nodeName?: string; position?: {x,y,z}; rotation?: {x,y,z}; // 角度制（度） scale?: {x,y,z}; duration?: number; // 秒，默认约 1；0=立即 restoreToggle?: boolean;// true：再次调用还原到执行前 }): boolean
// 阀门开度：绕本地轴旋转 45°
window.sceneApi.setTransform('valve_03', {
  nodeName: 'stem',
  rotation: { x: 0, y: 0, z: 45 },
  duration: 0.8
});

// 再次触发还原
window.sceneApi.setTransform('valve_03', {
  nodeName: 'stem',
  rotation: { x: 0, y: 0, z: 45 },
  restoreToggle: true
});
setUIVisible 可调用 UI
setUIVisible(elementId: string | string[], mode?: VisibilityMode | boolean): boolean

按 UI 元素 id（或 data-ui-id）控制面板显隐，支持数组批量。

window.sceneApi.setUIVisible('panel_alarm', 'show');
window.sceneApi.setUIVisible(['btn_a', 'btn_b'], 'hide');
playTour / pauseTour / stopTour 可调用 漫游
playTour(tourId?: string): boolean pauseTour(): boolean stopTour(): boolean

不传 tourId 时播放当前/默认路线。导出包可按 config/camera-tour-index.json 加载指定路线。

window.sceneApi.playTour();
window.sceneApi.playTour('tour_line_a');
window.sceneApi.pauseTour();
window.sceneApi.stopTour();
dispatch 可调用 调度
dispatch(action: UIAction): boolean

与 UI 编排「场景交互」使用同一套动作对象。见下一节动作类型。

window.sceneApi.dispatch({
  id: 'a1',
  trigger: 'click',
  type: 'object.setVisible',
  targetId: 'pump_01',
  params: { visibilityMode: 'toggle' }
});
onPointPatch 导出包 扩展
onPointPatch(patch: unknown): void

导出包内把补丁转发为浏览器事件 dt-point-patch，便于业务脚本监听测点更新。

window.addEventListener('dt-point-patch', (e) => {
  console.log(e.detail);
});
window.sceneApi.onPointPatch?.({ pointId: 'P-01', value: 1.23 });

4. dispatch 支持的动作类型

UIAction.type → 内部调用的 API 方法：

type含义实际调用
object.setVisible模型显隐setVisible
object.select选中模型select
object.focus飞向模型（兼容旧数据）focus
object.setMaterial改材质setMaterial
object.setTransform变换节点setTransform
camera.set相机移动setCamera
ui.setVisibleUI 显隐setUIVisible
tour.play播放漫游playTour
tour.pause暂停漫游pauseTour
tour.stop停止漫游stopTour
custom调用全局函数window[fnName]()
触发方式 trigger 供 UI 绑定使用：click / dblclick / mouseenter / mouseleave。脚本直接 dispatch 时可不依赖 trigger。

5. 与 SCP/1.3 指令对照

协议里的 SceneCommand.action 与现有 JS API 的映射关系（接入层落地后应这样桥接）：

SCP action 协议状态 建议桥接到 说明
setVisible 部分支持 sceneApi.setVisible JS API 已可用；差消息总线
setTransform 部分支持 sceneApi.setTransform 已有过渡；协议的 space/easing 未全覆盖
setMaterial 部分支持 sceneApi.setMaterial 单槽改色可用
setCamera 部分支持 sceneApi.setCamera 位置+注视点；FOV 需另扩
focusObject API 已有 sceneApi.focus 协议表标「暂不支持」偏旧；JS 侧已可调用
playCameraTour 支持 sceneApi.playTour 差 Agent 远程触发接入
stopCameraTour 支持 sceneApi.stopTour 同上
playTextureAnimation 支持 （编辑器配置 / 导出自动播） 尚未挂到 sceneApi 方法
stopTextureAnimation 支持 — 同上，无独立 API 方法
setPostProcess 支持 — 编辑器/导出配置生效；无运行时 sceneApi
setLight / setEnvironment 部分支持 — 仅编辑器面板；未暴露 sceneApi
setTrajectory 等 暂不支持 — 见协议第十节

6. 全局辅助对象（只读/内部）

这些一般由编辑器注入，业务侧优先只用 sceneApi：

全局变量说明
window.sceneApi对外控制 API（推荐入口）
window.__editorSceneThree.js Scene
window.__editorCamera透视相机
window.__editorControls轨道控制（含 target）
window.__editorTourPlayer编辑器漫游播放器
window.__editorTransformControls变换 Gizmo
window.cameraTour导出包漫游运行时（有漫游时）
导出包场景就绪后会派发事件：window.dispatchEvent(new CustomEvent('dt-scene-ready'))，可在此回调里再调 API。

7. 完整调用示例

function whenReady(fn) {
  if (window.sceneApi) return fn();
  window.addEventListener('dt-scene-ready', fn, { once: true });
  // 编辑器内也可轮询
  const t = setInterval(() => {
    if (window.sceneApi) {
      clearInterval(t);
      fn();
    }
  }, 200);
}

whenReady(() => {
  const api = window.sceneApi;

  // 1) 飞到设备
  api.focus('pump_01', { duration: 2 });

  // 2) 告警变色
  api.setMaterial('pump_01', {
    color: '#ff4444',
    emissive: '#ff0000',
    emissiveIntensity: 0.5
  });

  // 3) 显示告警面板
  api.setUIVisible('ui_alarm_card', 'show');

  // 4) 播一条巡检漫游
  // api.playTour('default_tour');
});
